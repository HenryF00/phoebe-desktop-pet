# Blackboard handwriting

`Xiaolai-Regular.ttf` is the unmodified Xiaolai v3.126 font from
[LXGW's original project](https://github.com/lxgw/kose-font/releases/tag/v3.126).
It provides a rounded handwritten Chinese and Japanese face for lesson text and captions.
