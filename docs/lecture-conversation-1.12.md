# 1.12 连续课堂

进入小黑板后，洛琪希停靠在黑板右下方，临时收起桌宠旁的普通输入。黑板下方保留课堂字幕、上一轮提问和无占位提示的透明输入；回车发送，麦克风仍为按住录音、松开发送，识别后的文字显示在上一轮提问位置。

追问继续使用当前板书、原始资料、行情快照和最近六轮问答。解释概念沿用现有资料，明确要求查最新信息时调用现有 Codex 委托通道，完成后在同一窗口更新板书。完整结果页可查看本轮回答和本课原始资料。关闭黑板恢复原来人物的位置、大小和输入状态；输入 `/聊天` 也可回到普通聊天。

板书和课堂字幕使用随应用打包的小赖手写体，许可证见 `assets/fonts/OFL-Xiaolai.txt`。字体只注册到当前进程，不安装到系统。正文与字幕分别保留易读字号，长字幕按实际文本控件高度调整窗口。

每次有效讲解由二至三个重点片段及最后独立的结束语组成。字幕语言与语音语言分别遵循设置中的中文、英文或日文选项。字幕、粉笔重点和教鞭姿势跟随真实音频开始与结束；取消或失败不显示完成结束语。

两张教鞭原图做了局部校色；透明导出改用明确的 sRGB 像素流程，修正旧 NSColor 色彩空间转换造成的提亮。保留原动作位置与尺寸，左右版本由确定性镜像导出。源图对照和颜色验证见 `qa/teaching-lighting/`。生成原画之间仍有少量材质差异。

验证记录：40 个 Python 测试；原生课堂交互、播放顺序、位置恢复和延迟事件测试；真实 Codex 财报追问生成成功，保留原始来源且更新同一课堂；真实日语 TTS 按顺序生成四段，最后结束语 5.28 秒。语音识别输入路由通过模拟识别回包测试，未使用用户麦克风录音。

行情沿用已有能力：美股历史日线快照，不把旧行情作为实时数据，也不虚构没有提供的价格。该版本未改变这项数据范围。
