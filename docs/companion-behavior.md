# 聊天动作与长期记忆（1.7.0）

## 使用

- 单击洛琪希聊天。提交消息后会托腮思考；按住麦克风录音时切换专注倾听。
- 回复按句选择自然、侧目、点头、失落或思考动作；动作跟随该句音频真正开始播放的时刻，而非模型生成完毕的时刻。
- 双击人物 → **记住的事…**：每行填写一个偏好或约定，保存后下轮对话生效。可以关闭使用，也可以清空内容再保存。
- 聊天中使用 **请记住：叫我小任** 保存一条；使用 **忘记：叫我小任** 按整条原文删除。没有冒号的普通聊天不会自动写入长期记忆。每次最多 300 字，总共最多 4000 字。
- “新对话”清空近期模型上下文，保留聊天记录和长期记忆；后两者各自独立。
- 右键 → 播放动作，可预览新增的聊天动作。实际聊天与播放中的回复优先于后台任务姿势；拖动、暂停仍保留原行为。聊天结束后恢复任务姿势或待机。

## 实现范围

采用当前已经校正的高清素材：思考使用托腮帧，倾听使用专注帧，点头使用正面与向下看，害羞使用侧目。画布仍为 1440×1400，不改旧帧，不加光晕或淡入淡出。两次生成的新害羞图因构图重绘、背景不透明未通过检查，候选只留在忽略的 runtime 目录，未安装。当前没有新增脸红细节，也没有嘴型同步。

`config/roxy-persona.txt` 是已启用的原创角色卡，独立于模型来源和字幕／语音语言。模型结构化回复在每个 caption/speech 对中增加 expression 枚举；该字段不会进入字幕、朗读或对话历史。旧的双字段回复仍能解析。

长期记忆保存在 `runtime/companion-memory.json`，原子替换，文件权限 0600，被 Git 忽略。只保存用户主动编辑或明确指令指定的内容；不自动扫描旧聊天、不让模型自行写入推断。启用时文本会随每次聊天发送给当前所选模型。关闭后保留本机内容，但不注入模型。UI 的清空操作在点击保存后生效。

本次没有增加搜索、屏幕感知、任意 MCP 或提醒执行。知识边界仍由现有隔离聊天通道保证，任务语音仍使用实际 Hooks 状态；没有把结束事件当作验证成功。

## 参考与取舍

参考 [Roxy-SKILL](https://github.com/umikok7/Roxy-SKILL/blob/4dc09150351deae8d914ee5e18a3f64798629340/SKILL.md) 的性格与情境表达组织方式，以及 [RoxyDesktopPet](https://github.com/SupaNeko/RoxyDesktopPet/blob/0c21a31d9a668f91a63c7a582d0554bf9989e51f/src-tauri/src/commands.rs) 的角色、上下文与情绪分层思想。没有安装外部 Skill 或复制其运行脚本；保留本项目增量字幕与 PCM 播放队列，不改成等待整段结果再显示。

## 验证

- Python 单元测试：增量 JSON 分块、表情枚举校验、中文参考方案、模型通道隔离，以及明确记忆指令、重复去重、关闭、精确删除、损坏文件保护。
- `CompanionHarness.swift`：实际静音 PCM 队列，后一段排队不提前换表情、模型完成不打断播放、取消后丢弃迟到事件、字幕保持完整；同时验证私有记忆存取和编辑器。
- `PetBehaviorHarness.swift`：聊天优先、恢复任务、停止回待机、手动预览、点头结束后保持最后一帧。
- 原有 CaptionTimingHarness 与 SettingsHarness 回归通过。
- `qa/companion-model.json`：真实 Codex 模型返回双语、称呼与表情枚举；其中“小任”为测试资料，未保存进用户记忆。
- `qa/companion-tts.json`：固定测试回复通过真实本地中文 TTS，收到带表情的 audio_start、PCM 块、audio_end、done，无合成警告。此项不是另一次完整模型调用。
- `qa/companion-behavior/`：设置窗口与动作渲染截图。
