# 小黑板讲解（1.10.1）

需要解释或可视化的回答使用小黑板，简单任务仍返回简短结果。小黑板先给一句结论，再呈现最多三项解释、有原文依据的关键数据与可比数值图表，保留完整结果和来源链接。洛琪希的语音只解释重点、含义与限制，不逐项念表。

## 使用

- 照常输入 `委托：……`，或右键选择项目后委托。也可以用 `小黑板：解释这个概念……` 发起讲解任务。
- 普通聊天里已有满意的回答：右键人物 → **把当前回复放到小黑板…**。这只整理当前回答，不重新执行任务。
- 人物右上角：蓝色转圈＝执行／排队；蓝色暂停＝需要处理；蓝点＝未读结果。有任务执行时，小点仍会提示其他未读结果。
- 点击标记：有未读结果时打开最新结果，否则打开任务列表。任务列表中的 **小黑板讲解** 也可以重新打开旧结果。
- 小黑板支持 **完整结果**、**听重点讲解**、**停止讲解** 和 **重新整理**。查看后清除该结果的未读标记；状态按任务完成版本持久保存。
- 双击人物打开同一个设置窗口，包含 **通用、聊天与声音、任务与小黑板、记忆** 四页。通用页集中大小、互动、动作跟随、暂停和重置位置。
- **任务与小黑板**：默认自动展示／讲解，也可改为只亮蓝点、点击查看；语音讲解可单独关闭。自动展示等正在生成或播放的聊天结束，并且不会覆盖另一个仍打开的小黑板。关闭当前黑板后继续展示排队结果。
- 重新启动时保留未读蓝点，不自动连续播放历史任务。已有旧任务可以直接从蓝点／任务列表打开并整理。

## 数据与模型

小黑板整理通过隔离的 Codex 聊天通道执行，会使用订阅额度，即便普通闲聊选择 DeepSeek。整理通道不能执行工具或访问文件；输入仅为任务标题、状态与最终结果。声音沿用本地 GPT-SoVITS 和当前语音语言。

结构化数据保存在 `runtime/blackboards/<id>.json`，权限 0600，按结果内容、任务状态、字幕及语音语言缓存。语言改变后重新整理。数值与证据必须逐字对应原文；图表至少两个可比项，单位必须原样出现在每个引用片段中，不可核对的数值或非有限数值会被丢弃。图表从零基线绘制，支持负数，数值标签保留源文本精度。没有数值的回答显示文字要点。

图表校验只验证原文引用及数字一致性，不代替对原始资料真实性和统计口径的核对。模型负责语义整理；原文最多取前 60,000 字送入整理，完整结果始终保留。若整理失败，会保留原文并提供重试，不把全文直接念出来。

界面使用 AppKit 原生文本与绘图，不执行回答中的 HTML、脚本或命令。来源链接需主动点击。语音请求带独立标识，停止、关闭黑板或开始新聊天后，旧合成结果不能突然播放。授课语音现在逐段合成、逐段入队；第一段可在后续段落合成时播放。普通聊天仍沿用流式文字和已有 PCM 播放。

## 验证

- Python：24 项，新增原文数值／单位校验、来源提取、缓存失效、私有权限与失败降级。
- 原生：`BlackboardHarness` 覆盖手动静音、自动等待、未读持久状态、原文切换、过期语音拒绝、真实 AVAudioPlayer 排队、四页设置嵌入与透明区域标记点击；原字幕、粘贴、授权和动画优先级回归通过。
- 真实 Codex 将人工虚构数据整理为 3 个要点、3 个关键数值、2 项对比图与中日双语讲解。耗时约 18 秒；本地日语 TTS 生成 37 秒音频，合成约 15 秒。这是本机此次样例的耗时，不保证每次相同。
- QA：`qa/blackboard/` 下包含模型结果、音频元数据与窗口截图。所有示例财务数值均明确标为虚构演示。


## 1.10.1 快捷入口与触发规则

执行方式和展示方式分开判断：

| 输入 | 行为 |
| --- | --- |
| `/委托 运行测试` | Codex 执行；简单结果用气泡，不必打开黑板 |
| `/小黑板 详细解释复利` | 隔离的概念讲解，不为普通知识解释创建执行任务 |
| `/委托 /小黑板 @HiPA 分析项目结构` | 在选择的真实项目中执行，并明确要求小黑板 |
| `@HiPA 检查构建` | 在该项目中委托任务；项目选择仅作用于这次输入 |
| `/聊天 一句话解释这个词` | 本次使用普通聊天，覆盖此前项目／任务模式 |

输入 `@` 搜索实际 Codex 项目，输入 `/` 显示方式列表；方向键选择，Tab 或第一次回车确认，填写正文后再次回车发送。有空格的项目会插入带引号的完整名称，项目身份和路径仍由后端公开接口验证。电子邮箱、URL 或普通正文里的 `@` 不被解析为开头命令。中文输入法仍在组词时不抢占键盘。

自动小黑板目前使用可解释的规则：详细解释、原理讲解、财报、数据分析、图表要求、对比差异，以及包含表格或多步解释的较长任务结果。普通寒暄、短词义和一句话回答不自动开板；“不用小黑板”“简短回答”可抑制自动展示。明确 `/小黑板` 的优先级最高。这不是无限制的语义分类器，未识别的场景可显式指定。

财报、股价或需要最新资料的解释仍走工具委托路径；普通概念解释只走隔离聊天。打开的小黑板可以作为后续聊天的资料上下文；讲解内容也加入本轮对话历史，方便追问。

## 授课字幕、重点与动作

每段讲解都携带 `caption / speech / focus / gesture`。实际播放开始才更新本段字幕、圈注与姿势；提前收到下一段音频不会改变当前重点，最后一段播放结束后才退出授课状态。

字幕作为独立半透明窗口附在小黑板下方，随黑板移动、缩放，并为字幕预留屏幕底部空间。长字幕按内容撑高，板书滚动不会遮挡字幕。可在 **双击人物 → 聊天与声音 → 字幕语言** 中选择中文、English 或日本語，与语音语言独立。如果两者均为日语，字幕直接使用实际朗读的日文。原聊天气泡与授课字幕分开维护。

板书仅使用红色粉笔圈标重点，圈住结论、关键数值、图表或章节标题。粉笔颗粒使用固定种子绘制，重绘时纹理不闪动；没有指示杖、星形或其他装饰。支持系统“减少动态效果”。

人物现有校准素材编排为“抬手讲解、讲解站姿、看向板书、点头强调”，依据实际音频播放时间编排动作，朝向随黑板在人物左／右侧调整。只复用已校准的立绘，没有新增手持教鞭素材。授课音频排队期间不会提前切换字幕或动作。

新增验证：28 项 Python 测试；`LessonHarness` 实测键盘补全、项目范围、Unicode、实际音频队列、字幕／焦点／姿势同步、日本語字幕和简单任务不弹黑板。`qa/lesson/smoke.json` 记录真实 Codex 概念讲解 → 板书整理 → 三段本地 TTS，未创建委托任务；此次第一段语音合成约 7 秒，三个片段合计约 47 秒。`qa/lesson/` 保存原生窗口截图。耗时仅为本机本次样例。
