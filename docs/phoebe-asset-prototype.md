# 菲比 2D 动画素材原型

本机原型使用用户提供的两张 WebP：`/Users/henryfang/Downloads/8204c53c6fdf478ab0882c862ced1cd220250212.webp`（完整站姿）和 `/Users/henryfang/Downloads/b88abc8d9d404801b6c5910790a534ba20241122.webp`（近景）。两张源图都带 Alpha，但透明区有黑色横条及杂色残留。

用内置 imagegen 做了两次 `background-extraction` 编辑，分别以完整站姿和近景为编辑目标、另一张为身份参考。完整图用于透明桌宠窗口，近景用于聊天窗头像。输出位于 `apps/desktop/public/pet/phoebe-full-prototype.png` 和 `apps/desktop/public/pet/phoebe-portrait-prototype.png`；两张原型图已被 Git 忽略。原始 WebP 没有改动。

最终提示词要点：保留菲比原有五官、帽子、金发、蓝白黑教士服、法杖、全身比例或近景构图；仅移除背景、黑色横条、彩色碎片，输出真实透明 Alpha；不加入文字、场景、阴影、额外人物或道具，也不转换成 Q 版或像素风。完整图要求帽尖、法杖、双腿和双靴都在画布内；近景图不补画原图之外的腿。

后续以完整站姿为编辑目标，通过内置 imagegen 的 `precise-object-edit` 生成闭眼帧 `apps/desktop/public/pet/phoebe-blink-prototype.png`，再以同一张图作角色参考，通过 `identity-preserve` 生成挥手姿势 `apps/desktop/public/pet/phoebe-wave-prototype.png`。闭眼提示词限定只闭合双眼、维持原有全身姿态与透明背景；挥手提示词限定同一帽子、服装、长发、法杖、靴子与落脚位置，仅将手势变为友好的挥手。两张新图也已被 Git 忽略，原图没有覆盖。

2026-09-16 起，运行时不再使用聊天海报卡片或局部叠层。`apps/desktop/public/pet/animations.json` 作为动画清单，所有消费帧统一为 `1004×1567` RGBA、脚底对齐，并使用 `*-v1.png` 版本化文件名。助手模式包含待机、眨眼和挥手；聊天模式新增合手待机、闭眼、托腮思考和开掌说明四种透明全身姿态。双手都没有握住权杖的动作禁止显示权杖；挥手帧只允许非挥手手持一根完整连续的权杖，禁止断截、悬浮、复制武器或在挥手手后保留第二件武器。

2026-09-16 的 v2 动作补丁修复了聊天眨眼：闭眼帧复用待机帧的完整 Alpha 轮廓，仅眼部矩形 `x=445..609, y=166..250` 发生变化，因此不会在切换时出现全身黑边。聊天挥手新增无权杖的准备帧和峰值帧；助手挥手新增持一根完整权杖的准备帧。动作包另加入工具执行、倾听／等待、害羞、轻微担忧和取消复位状态。素材生成方式、提示词边界和验收结果记录在 `apps/desktop/public/pet/phoebe-animation-v2.source.txt`。

前端根据清单中的逐帧时长直接换图，不做图片淡化；CSS 只提供幅度很小的呼吸、点头、说话、思考和位移。点头、开心、挥手和取消采用 `one-shot + holdLast + returnToIdle`，不再无限循环。状态优先级是手动预览、失败、取消、工具执行、思考／合成、倾听／等待确认、实际语音播放／短时回复反应、空闲挥手、待机。自动挥手只有在无任务、无语音、无短时反应、聊天窗和菜单关闭且连续空闲 120 秒后才触发；任何交互或状态变化都会重新计时。系统开启“减少动态效果”时停用连续位移。这仍是本机逐帧动画，不是 Live2D 分层模型；要制作口型同步或更细腻的布料运动，应以分层原画或授权素材重新制作。公开发布、上传或分发安装包前需重新核对素材来源、授权和库洛二创规则；不能将本机原型视为已获发布许可。
