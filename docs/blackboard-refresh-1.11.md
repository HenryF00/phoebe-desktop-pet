# 小黑板 1.11

## 交互

右上角只有齿轮：听重点、停止、完整结果与来源、重新整理、股票图样式与周期、总设置。准备板书/语音时只显示原生转圈；出错保留可操作的文字。字幕继续在黑板下方，跟随真实播放片段。

板面为本地确定性细颗粒深绿板面、木质边框，标题与正文使用系统楷体（缺失时回退系统字）。粉笔圈采用连续圆角路径，颗粒限制在笔画内部，消除原先向外散射的刺。动画遵守减少动态效果设置。

## 授课资源

内置 image_gen 生成两张带木质教鞭的原画差分：斜指/平指。统一1440×1400画布、脚底/帽顶位置；透明导出，另有向右版本。授课各阶段均使用教鞭资源；不再用挥手/看向旁边假作教鞭动作。原始素材、提示词、导出脚本均保留。生成帧与原画仍可能有细微面部/服装绘制差异。

## 股票图与 AInvest 检查

本机 AInvest desktop 存在 `.supercode/extensions/plugins/trading-studio/skills/tradingstudio-widget-super-chart/SKILL.md`，支持股票代码、周期、K线/面积样式、指标、标注等操作协议。

它是已注册 widget 的控制说明，不是可独立执行的画图 skill。实际依赖 `@ainvest/biz-components/super-chart`、`@hx-klineview/core`、`@ths-m/HXKline`、应用状态和行情登录。Roxy 为 AppKit/Python，不能只复制 SKILL.md 就获得其组件。此次参考代码/周期/样式的控制结构，自行实现原生绘图；没有复制公司凭据、私有组件或引入 AInvest 运行环境。

数据来自 Nasdaq historical HTTP 接口：有限读取最多120根日线，校验代码、日期、OHLC关系、数值与成交量，使用系统现有HTTPS代理。支持明确的美股代码与常见名称（英伟达、苹果、特斯拉、微软、亚马逊、谷歌）。不同市场与实时分时行情尚未接入。

K线/面积走势＋成交量，20/60/120交易日切换，默认60；标明日期、USD、Nasdaq、历史日线和未自行复权。日线红涨绿跌指收盘相对开盘；顶部区间变化按区间首尾收盘计算。行情摘要进入讲解输入，保持日期口径一致，不让语言模型生成K线。板书缓存保留当时快照；用齿轮重新整理刷新。获取失败保留原文/讲解并提示，不生成假行情。来源链接在完整结果与来源内。
